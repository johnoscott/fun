# Changelog

All notable changes to **Cyber Rain** are documented here. Format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## 2026-10-05

### Changed

- Moved into `experiments/warp-wave/` as part of the repo reorganisation; `.deck/ai/` checkpoints are no longer tracked.

## 2026-07-12

### Added

- `cyber-rain.html`: Matrix-style glyph rain with phosphor trails, mouse repulsion, click bursts and an FPS meter.
- `cyber-rain-styles.html`: variant with selectable style presets (glyph sets, colours, speed, trail length, flicker).
