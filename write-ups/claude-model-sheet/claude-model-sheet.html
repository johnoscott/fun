What changed under you

stale prior → current API
400

budget_tokens

Removed on Fable 5, Opus 5, Opus 4.8 and 4.7, and Sonnet 5. Still functional on Opus 4.6 and Sonnet 4.6 as a transitional escape hatch only. Reach for effort instead.

400

Assistant prefill

Prefilling the last assistant turn errors on every 4.6-and-later model. Shape the output with output_config.format or a system instruction.

400

temperature, top_p, top_k

Sampling parameters are gone from Fable 5, Opus 5/4.7/4.8 and Sonnet 5. Opus 4.6 and Sonnet 4.6 still accept them.

Silent

Thinking display

Defaults to omitted on Fable 5, Mythos 5, Opus 5/4.8/4.7 and Sonnet 5 — a change from 4.6, where it was summarised. If you stream reasoning to users it now looks like a long pause; set display: "summarized".

200

stop_reason: refusal

A declined request arrives as a normal 200 with a category in stop_details. Check stop_reason before reading content, and turn on server-side fallbacks.

New

Server tool versions

Web search and fetch moved to the _20260209 variants with dynamic filtering. They run code execution internally — don't also declare code_execution alongside them.

Fast

Fast mode

Opus 5 and Opus 4.8 only, first-party API only. Needs all three: the beta endpoint, the fast-mode-2026-02-01 flag, and top-level speed: "fast". Billed at $10 / $50.

Cache

Mid-conversation system messages

On Opus 5, Opus 4.8, Fable 5 and Mythos 5, append a system-role entry to messages rather than editing the top-level prompt — the cached prefix survives. Not on Sonnet 5.

The request to start from

python · anthropic 
# Streaming, because 128K max_tokens will outlast the HTTP timeout.
with client.messages.stream(
    model="claude-opus-5",
    max_tokens=64000,
    thinking={"type": "adaptive", "display": "summarized"},
    output_config={"effort": "xhigh"},
    messages=[{"role": "user", "content": prompt}],
) as stream:
    message = stream.get_final_message()

if message.stop_reason == "refusal":
    handle(message.stop_details.category)
