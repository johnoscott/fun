# Changelog

## [1.0] - 2026-10-07

### Added

- Self-contained cartoon 3D aquarium with an automatically cruising submarine viewpoint.
- A 60-second day/night cycle with rising and setting sun and moon.
- Colorful fish, sharks, rays, turtles, jellyfish, octopuses, seahorses, coral, and kelp.
- Automatic underwater weather: clear currents, bubble showers, snowfall, and electric squalls.
- Fullscreen, pause, weather selection, time skipping, and controls that fade when idle.
