# Changelog

All notable changes to **Ethereal DNA** are documented here. Format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## 2026-10-05

### Changed

- Moved into `html-screensaver/dna-screensaver/` as part of the repo reorganisation; duplicate "copy" files renamed to `-v1`/`-v2` by date.

## [2.0] - 2026-08-07

### Changed

- `dna-screensaver-v2.html`: top-right HUD now shows the active epoch name and a description of each period (Abiogenesis onwards).
- Bottom timeline draws animated silhouettes for each geological period instead of text labels; timeline markers are clickable to jump between epochs.
- Added wrapped canvas text rendering; FPS counter and audio indicator moved into the epoch panel.

## [1.0] - 2026-08-07

### Added

- `dna-screensaver-v1.html`: 60-second "journey of life" DNA screensaver with sci-fi HUD, scrolling log, mutation alerts, sound toggle and a Hadean → Cenozoic timeline.
